# Safety Gate Checklist

使用前先确认目标和路径；任何不确定项都暂停并询问，不猜测。

## 变更前

- [ ] 目标 profile 已明确
- [ ] 目标文件、绝对路径和变更范围已明确
- [ ] 已检查 `~/.dsh/插件能力地图.md`，确认没有可复用能力被重复实现
- [ ] `package.json` 已备份
- [ ] `cordis.patch.yml` 已备份
- [ ] 可隔离验证或 dry-run 的路径已确定
- [ ] 回滚命令已写出，并核对目标路径

## 兼容性和污染检查

- [ ] 目标包是否声明 engines
- [ ] 目标包是否依赖或安装 `@deepseek-ai/*` 宿主核心包
- [ ] profile `node_modules/@deepseek-ai/` 未出现重复核心包
- [ ] patch 新增项使用 `- insert: [{ id, name, config }]`
- [ ] 没有通过 dshmarket 开关误改手写 patch

## 执行和验收

- [ ] 一次只执行一项独立变更
- [ ] 用户已明确确认有副作用的动作
- [ ] 新会话可以创建
- [ ] 预期功能可见并工作
- [ ] 非目标任务不会误触发
- [ ] 回滚命令已验证或做过 dry-run
- [ ] 结果已写入 CHECKPOINT.md

## 强制暂停条件

出现以下任一情况，禁止继续：

- 目标路径不明确
- 没有备份却准备改 profile
- 无法说明如何回滚
- 发现核心包重复安装
- patch 使用未知 id 的裸条目
- 隔离验证失败但准备直接改 desktop
- 必需验收项失败
